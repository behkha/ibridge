Calls on the iPhone

Phase 2 lets a call ring, be answered and be spoken entirely on the iPhone while the Galaxy stays in a pocket. Four screens change. Each decision below has its options side by side with the same data; the recommended option is marked.

How it works
  1. Once, on the Galaxy: iBridge pairs with the phone's own Wireless debugging (you type a 6-digit code). That lets iBridge start a small helper with the phone's debugging rights, which can hear and speak into a call.
  2. iBridge then keeps Wireless debugging off. After a restart it switches it on for a few seconds over Wi-Fi to start the helper again. A running helper does not need Wi-Fi.
  3. A call rings on the iPhone with the normal iPhone call screen. Answer there: the Galaxy mutes its microphone, turns its earpiece down to the minimum, and the call's sound travels encrypted over Bluetooth.
  4. The keypad and call history can place calls through the Galaxy the same way.
